# BillZen v0.1.3 — Precision Ledger

A cleaner offline business workspace, with refreshed Reports and Settings-only language selection.

## Download

**Android ARM64:** Download `billzen-beta-v0.1.3-arm64-v8a.apk` below (20.54 MB). Requires Android 7 or later and a 64-bit ARM phone. This remains a beta build.

Install over your existing BillZen app; do not uninstall or clear app storage to update. This release retains the original package and signing certificate. Android may ask for permission to install from your browser/files app and confirmation to install.

## What's changed

- Refreshed Precision Ledger Dashboard, Cashbook and Reports, with responsive layouts and dark/light themes.
- Language selection lives in Settings; English, Malayalam and Arabic are supported, including right-to-left layout.
- Removed platform/framework badges and internal diagnostics from the main interface.
- Improved Reports date validation, category filters, loading/error feedback, CSV category names and A4 print/PDF output.
- Existing offline data storage and updater signing identity are retained.

## Updates

Android versionCode: **1008**. The updater checks this repository's signed `android-update.json`. Supported older updater-enabled installations can discover this release; installation needs Android user confirmation. Apps without the updater need this APK installed once. Merely pushing source code does not distribute app updates.

The APK, signed Android manifest and checksums are attached. The manifest is consumed by BillZen; friends only need the APK. Future releases must retain the same signing identities and use a higher versionCode.

This release distributes Android ARM64 only. Desktop installers and desktop updater metadata are not included; an Android release does not update desktop installations.
