# BillZen v0.1.5 — Stock & Company Cashbook

This release brings all completed company-money, customer, inventory and interface changes since v0.1.3 into fresh installable packages. Offline data remains on each device; no cloud synchronization is introduced.

## New and improved

- Product **Manage Stock**: add/reduce quantities, before/after preview, immutable history and opposite correction entries. Atomic ledger updates, insufficient-stock checks and duplicate-save protection.
- **Transfer money** between Cash/Bank accounts, paired reversal, shared transfer documents, and reports that separate transfers from business receipts/payments.
- Customer-linked Cashbook entries/history and party filters in Reports.
- Complete workspace backup1.1, legacy transfer-free1.0 import and stock/transfer restoration checks.
- Cleaner Reports filters, small-window scroll clearance, responsive navigation and consistent selector/dialog motion with reduced-motion support.
- English, Malayalam and Arabic/RTL workflows; local theme preference.

## Install or update

Export a local backup in Settings before updating an existing business installation. Keep the same app/data location; do not uninstall Android or clear its storage. Android versionCode1010 retains the original package/certificate and signed update-manifest identity. Updater-enabled Android users can check Settings → Updates after this release is published; Android still asks for installation consent.

On Mac, open the DMG and drag BillZen to Applications. This beta uses an **ad-hoc signature, without Apple Developer ID/notarization**. macOS may require a per-app approval under System Settings → Privacy & Security after the first open attempt, as described in [Apple's official instructions](https://support.apple.com/en-us/102445). It is not an Apple-verified/App Store build. Do not disable Gatekeeper globally.

Windows installer is not Authenticode-signed and may show an unrecognized-publisher prompt. Desktop automatic-update feeds are not configured by this release; download the matching new installer. The Android feed does not update desktop applications.

## Scope and verification

The product remains a beta. Automatic invoice-finalization stock decrement, supplier purchase bills and device synchronization are separate future work. Stock adjustments do not create payments automatically.

All installers contain the same v0.1.5 application source. Each build-info file records its actual packaging revision/run; the Mac packaging-only verification correction does not change application code. Desktop workflow runs publisher/frontend/native tests and verifies Mac ARM64 signature integrity/Windows icon resources before collecting artifacts. Local Android checks require the original certificate, current embedded assets, release flags and16KB alignment. Source checks and hosted packaging do not establish physical Mac/Windows/Android device runtime acceptance; build-info records this distinction.
