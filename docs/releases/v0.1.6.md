# BillZen v0.1.6 — Desktop in-app updates

This desktop bootstrap release adds **Settings → App updates → Check for updates → Download update → Install update** for Windows x64, macOS Apple Silicon and the Linux x64 AppImage edition.

Desktop v0.1.5 users must install the matching v0.1.6 installer once. Later published versions can be downloaded and installed from the app. Save edits before installing; BillZen creates a local recovery snapshot and restarts after installation. Local company records stay on the device.

- Windows: `BillZen-0.1.6-Windows-x64.exe`.
- Apple Silicon Mac: `BillZen-0.1.6-macOS-AppleSilicon.dmg`; copy to Applications first.
- Linux with in-app updates: `BillZen-0.1.6-Linux-x64.AppImage`; keep it in a writable folder.
- Linux Debian package remains available for manual package updates.

The native service verifies pinned-key signatures and authenticated release versions, supports cancellable downloads and refuses installation before verification. Database preparation failures preserve normal access; failed installations report an error rather than claiming success.

Mac packages are ad-hoc signed, not notarized/Apple Developer ID signed. Windows packages are not Authenticode signed. OS security/installation consent can still appear. No Mac Intel/iOS package is included.

This is a desktop-only release. The latest Android feed continues to offer the existing signed v0.1.5/code1010 APK; Android users do not need to install a desktop package. No new billing features or cloud synchronization are introduced.
