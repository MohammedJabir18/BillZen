# Regional scope

India and the six GCC countries are intended markets. Implemented foundations include currency/exponent validation for INR, AED, SAR, QAR, KWD, BHD and OMR, plus English/Malayalam/Arabic resources and an RTL interface mode. Translation coverage and regional date/number entry still require acceptance testing.

This is not a GST or VAT compliance certification. Invoice issuance, numbering, registration identifiers, tax treatments, legal text, QR contents, signing and submission requirements depend on jurisdiction and taxpayer circumstances. Country-specific rules must be checked against current official sources before an implementation is approved for use.

Optional cloud synchronization is distinct from statutory reporting obligations. A fully offline point-of-sale goal cannot be treated as permission to issue every regulated tax document offline or submit it later. Define the permissible offline behavior for each supported regime before implementing an outbox.

The earlier `tax-and-e-invoicing-matrix.md` is a design input, not an implemented statutory connector or current legal authority.
